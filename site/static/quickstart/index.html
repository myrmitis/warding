Before you set up Warding.

Local beta. Public source is available on GitHub.

1. Bring your agent

Install and sign in to a supported coding-agent CLI. Warding uses your own agent login. Provider terms, subscriptions and usage limits apply.

Chat uses one chosen harness. Capabilities and approval behavior vary by harness and launch path.

2. Check source availability

The intended setup builds Warding from a reviewed source checkout. Clean-machine installation remains unqualified; check source status before attempting setup.

Public source available

Public source and setup documentation are available on GitHub. Release downloads remain unavailable. A clean install and live workflow are not yet verified.

Source status Read beta notes

No desktop app yet. No signed installers yet. No hosted service. A clean install and live end-to-end workflow have not yet been verified for this seed.

3. Give the work a shape

After obtaining a reviewed checkout, the intended workflow opens the local browser dashboard to start a chat and review project context. Schedules, checkpointed tasks and focused background agents are available through the dashboard or CLI.

Optional approvals require Interactive mode for gated tool calls. They do not replace a security boundary. Read the security model before granting access to tools or files.

Schedules, channels, overnight runs and subagents routed through another installed harness are not yet runtime-verified. Check the beta notes before relying on them.

Source and attribution

Warding by Myrmitis is Apache-2.0 software. Required upstream attribution is preserved in NOTICE. Read the project lineage and source availability and beta limits.
