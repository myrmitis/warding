Privacy

A plain-language summary, not a contract drafted by a lawyer. It covers this website and the Warding software. Updated 2026-09-29.

This website

The site collects nothing about you unless analytics is configured. No analytics script is configured today, so none is loaded. If analytics is turned on later, it will be a cookieless provider, and this page will name it.

There are no tracking cookies. Your theme choice and any waitlist address you type are kept in your own browser's storage so a reload remembers them; they are not sent anywhere by that.

The static host that serves these pages keeps its own standard request logs, under its own policy.

Where a waitlist email goes

There is no mailing-list backend yet. When you join a list, the form tries these in order and uses the first one that is set up:

  1. A list endpoint we configure (not set up today): it receives your email, the list name and any answers you typed.
  2. Your own mail app, with a message to us prefilled (not set up today). Nothing is sent until you press send.
  3. A GitHub Discussion (not set up today): you post the reply yourself, under your GitHub account, in public.
  4. With none of those set up, the form does not take an address and shows the source availability and beta limits.

We use a waitlist address only to tell you about the thing you signed up for. We do not sell, rent or share it.

The software

Warding runs on your machine. Its data home, sessions, memory and audit log stay there. The default build sends nothing to us: there is no server of ours in the loop and no telemetry to us by default.

It does talk to the services you point it at: your agent vendor, through the vendor's own CLI under your login, and the chat apps you connect. What those services do with the data is covered by their terms, not ours.

One download is not yours to choose by default: the embedding model is fetched from a CDN address inherited from the upstream codebase the first time embeddings are used, and checked against a pinned hash. You can point memory.embed_model_url at a mirror, or supply your own model file, to avoid it.

If you pay us

Founding Supporter checkouts run on Polar; setup sessions and pilots on Stripe. They handle the card details; we receive your name, email and what you bought.

Contact

Public contact setup is pending. Read the contact status. No mailing-list backend or analytics script is configured today.
