Compare

The other tool's strengths first. Primary sources only.

  • When to use Anthropic's built-ins, and when to use Warding.

    Routines run without approvals and have per-account caps. Warding: your box, mid-run approvals in five chat apps, ten channels, the harness you choose.

  • Chat-reachable like OpenClaw, built for coding agents.

    Want an agent you can text from Telegram, but for real code work? Compare on agents, channels, sandboxing, policy and audit. Sources cited.

  • If you are at the keyboard, use Paseo.

    Paseo runs several agents at once while you watch. Warding runs the agent you choose unattended, under a policy it can't edit. Use both.

  • Same engine as the project we fork. Here is what we add, and what we lack.

    Warding derives from an Apache-2.0 agent workspace. The shared engine, our changes, and the original project's strengths.
