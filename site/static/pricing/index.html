Questions people ask before paying

Do I need to pay you to use my own Claude plan, Codex or Goose?

No. Warding launches the official CLI under your own login. We never see your keys and we never mark up tokens.

Is there a run cap?

Not from us. Your vendor's plan limits and their terms for unattended use apply and may change; for shared or production automation, use an API key.

What exactly does the Supporter money buy today?

Nothing yet, because nothing is sold yet. The tier is a free waitlist until every item on its card exists; the day it opens, those items are delivered through Polar.

Is Founding Supporter a pre-order?

No. Future features are a bonus labelled “in development”, not the thing sold.

Why is Setup on Stripe and Supporter on Polar?

Polar is the merchant of record for digital goods; it does not allow human services, so services and pilots run on Stripe.

Can my company just sponsor the project?

GitHub Sponsors. We don't sell sponsorship on Polar.

Refunds?

Setup and pilots: full refund if the written outcome is not reached. Supporter: 14 days, no questions.

Has a third party reviewed this?

No third-party audit yet. Read the scope statement and, once it ships, run the bypass script.

Windows?

Source install only; agent processes fail closed until you opt in.

Want the one-line installer?

The install is a clone and a script today. The one-line installer is in development.
